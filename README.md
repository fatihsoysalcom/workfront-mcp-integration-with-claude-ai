# Workfront MCP Integration with Claude AI

Demonstrates an integration bridge between Adobe Workfront campaign management and Claude via Model Context Protocol (MCP) tools. It simulates Workfront API interactions and handles automated task creation and campaign status reporting triggered by AI tool calling.

## Language

`python`

## How to Run

Run `python workfront_mcp_claude.py` using Python 3.8+.
